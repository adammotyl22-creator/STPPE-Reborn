═══════════════════════════════════════════════════════════════
 QUICK START
═══════════════════════════════════════════════════════════════

1. Upload to Teensy:
   → Teensy_4.1/IK_Control/IK_Control.ino

2. Upload to ESP32 Master:
   → ESP32_C3/Master_Gesture_ESPNOW/Master_Gesture_ESPNOW.ino
   → Note MAC address

3. Upload to ESP32 Slave:
   → ESP32_C3/Slave_ESPNOW/Slave_ESPNOW.ino
   → Note MAC address
   → Update Master code with Slave MAC
   → Re-upload Master

4. Wire ESP32 Slave to Teensy:
   ESP32 TX (GPIO 21) → Teensy RX (Pin 0)
   ESP32 RX (GPIO 20) → Teensy TX (Pin 1)
   ESP32 GND → Teensy GND

5. Power on and test!
   → Press clutch on Master
   → Tilt hand → Robot moves!
